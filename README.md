# Food Image Classifier
A convolutional neural network trained on images of certain foods that makes predictions based on given images.

## Main Features
- CNN Model - Convolutional Neural Network trained on 10 food categories.
- Image Classification - Classifies uploaded images into food types.
- Web Interface - Built with Streamlit for simple image upload and prediction.

## Technologies Used
- Python 3.11+
- Streamlit
- Scikit-learn
- PyTorch
